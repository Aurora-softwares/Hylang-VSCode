# Changelog

## 0.2.1

- Added a PNG extension icon derived from the existing Hydrogen SVG.

## 0.2.0

- Branded the extension as Hylang Language Tools.
- Parse `hy check` output from both the released compiler and C++ SDK.
- Check saved files and optional project targets, and format through `hy fmt` when available.
- Documented VSIX export and installation.

## 0.1.0

- Initial local VS Code extension for Hydrogen / Hylang.
- Added syntax highlighting, snippets, formatting, structural diagnostics, and optional `hy check --json` diagnostics.
